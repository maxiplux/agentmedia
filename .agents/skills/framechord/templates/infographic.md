# Purpose
Help adult learners compare the supplied categories at a glance.

# Direction
Use a clear top-to-bottom reading order, large legible labels, consistent
spacing, restrained teal and amber accents, and neutral background.

# Data and copy
Render only the exact supplied title, section copy, labels, values, units,
and source notes in infographic.yaml. Do not introduce new facts.

# Review criteria
Check all text, numeric formatting, reading order, contrast, and chart honesty.
