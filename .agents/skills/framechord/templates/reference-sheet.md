# Character reference-sheet candidate

## Identity source
Use the selected original images with their exact recorded provider and model.
This is a candidate, not an accepted replacement for the originals.

## Required views
Full body front, three-quarter and side views, plus a face/detail close-up.
Keep hands, feet, antennae and accessories inside the frame. Plain neutral background,
consistent scale, even light. Avoid decorative text and overlapping figures.

## Fixed identity
Copy the selected visual profile here: face geometry, hair silhouette, head/body
ratio, limb lengths, materials, palette, clothing and distinctive accessories.
Do not invent missing details; identify ambiguities for the user before acceptance.

## Acceptance
Compare every panel against the original. Reject redesigned anatomy or blended
identities. The user selects candidate references before persona accept is called.
